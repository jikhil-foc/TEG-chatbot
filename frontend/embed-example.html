Third-party page

This page simulates any website embedding the TEG chatbot via a single script tag. Build the widget bundle first with npm run build:widget, then serve dist/widget/teg-chatbot.js. 

<script
  src="/teg-chatbot.js"
  data-auto-init
  data-api-url="http://localhost:8000"
  data-title="TEG Assistant"
  data-subtitle="Ask about TEG levels and exams"
></script>
